# ExitAnt USA TBV (복리 터틀) — 한국투자증권

한국투자증권 계좌로 미국 주식 · ETF 를 **현물(롱만)** 으로 터틀 전략 매매하는 자동매매 봇을 **내 Render 계정**에 백그라운드 워커로
띄웁니다. 봇은 미리 빌드한 Docker 이미지로 돌고, 이 저장소에는 **Render Blueprint(`render.yaml`)만** 있습니다 — 소스 코드는 없습니다.

## Render 에 배포

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/ExitAnt-dev/turtle-hantoo)

```
https://render.com/deploy?repo=https://github.com/ExitAnt-dev/turtle-hantoo
```

1. 버튼(또는 링크)을 누르고 Render 에 로그인합니다.
2. Render 가 `render.yaml` 을 읽어 **백그라운드 워커 하나**를 제안합니다.
3. 아래 환경변수 5개를 입력합니다. `sync: false` 라 배포 화면에서 묻고 **내 Render 계정에만** 저장됩니다.
4. **Apply** 를 누르고 첫 배포가 끝날 때까지 기다립니다.
5. 텔레그램에서 봇에게 **`/start`** 를 보냅니다. 약관에 동의하면 **「🧪 모의 투자 모드로 진행할까요?」** 를 묻습니다 — 아래 「모의 투자」 참고.
   고른 모드로 한국투자증권 연결을 확인한 뒤 설정으로 넘어갑니다. 서버가 다시 시작되면(재배포 · Render 의 인스턴스 교체) 봇이 묻지 않고
   이전 설정 · 모드로 매매를 이어 갑니다.

## 배포 전에 준비할 것

- **해외주식(미국) 거래가 되는 한국투자증권 계좌.**
- **KIS Developers 앱키 · 앱시크릿(실전투자).** [KIS Developers](https://apiportal.koreainvestment.com) 에서 API 신청 후 발급합니다.
- **달러(USD) 예수금** — 또는 한국투자증권 **통합증거금 서비스** 신청(원화로 달러 주문). 둘 다 없으면 미국 주식을 살 수 없어 진입이 미뤄집니다.

## 환경변수

| 변수 | 넣을 값 |
|---|---|
| `HANTOO_APP_KEY` | KIS Developers 앱키(실전투자) |
| `HANTOO_APP_SECRET` | KIS Developers 앱시크릿 |
| `HANTOO_ACCOUNT_NO` | 계좌번호 8자리(`12345678`) — 상품코드까지 10자리(`12345678-01`)로 넣어도 됩니다 |
| `TELEGRAM_BOT_TOKEN` | [@BotFather](https://t.me/BotFather) 가 발급한 봇 토큰 |
| `TELEGRAM_CHAT_ID` | 내 텔레그램 채팅 ID — 봇은 다른 사람의 메시지에 답하지 않습니다 |

## 모의 투자

약관 동의 뒤 **「🧪 예 — 모의 투자」** 를 고르면 봇의 모든 주문 · 조회가 **한국투자증권 모의투자 서버**로만 나갑니다 — 실제 돈은 움직이지 않습니다.
**「💼 아니오 — 실전 투자」** 면 실제 계좌로 매매합니다. 고른 모드는 고정 백업에 함께 저장돼 재시작 뒤에도 이어집니다. 모의투자면 메인 메뉴와
현황 리포트에 「🧪 모의투자」가 붙습니다.

- 모의투자는 [KIS Developers](https://apiportal.koreainvestment.com) 에서 **모의투자 신청**과 **모의투자용 앱키**, **모의투자 계좌번호**가 필요합니다.
- **모의투자만 쓸 때:** 위 표의 `HANTOO_APP_KEY` · `HANTOO_APP_SECRET` · `HANTOO_ACCOUNT_NO` 에 모의투자용 값을 넣고 「예」를 고르면 됩니다.
- **실전 · 모의를 둘 다 둘 때:** 위 칸에는 실전 값을 두고, Render 서비스 → **Environment** 에 아래 값을 더해 저장합니다(저장하면 다시 시작합니다).
  넣지 않은 칸은 위 칸의 값을 모의투자에도 씁니다.

| 변수(선택) | 넣을 값 |
|---|---|
| `HANTOO_MOCK_APP_KEY` | 모의투자용 앱키 |
| `HANTOO_MOCK_APP_SECRET` | 모의투자용 앱시크릿 |
| `HANTOO_MOCK_ACCOUNT_NO` | 모의투자 계좌번호 8자리 |

- 연결이 안 되면 봇이 어느 칸이 비었는지 · 읽을 수 없는지, 실전 · 모의가 다른 키를 넣었는지 알려 주고 「다시 확인」 · 「모드 다시 고르기」를 냅니다.
- 설정을 마친 뒤 모드를 바꾸려면 TanQuant 세팅 글을 **대화창에 바로 붙여 넣고** 「바꿀까요?」에 **예**를 누릅니다 — 지금 설정을 지운 뒤
  약관 → 모드를 다시 묻습니다(설정 변경 → 📋 TanQuant 세팅 붙여 넣기는 지금 모드 그대로 세팅만 바꿉니다). 보유 주식이 있으면 먼저 묻고,
  봇이 건 주문만 걷은 뒤 보유 주식은 그대로 둔 채 손을 뗍니다(그 계좌로 돌아오면 다시 떠맡지 않습니다).

## 봇이 하는 일

- **터틀 전략, 롱만 — 봉은 1H · 4H · 1D 가운데 고릅니다.** 미국 주식 · ETF 90여 종목(주식 · ETF 두 쪽) 가운데 최대 20종목을 고릅니다. 전략은
  셋입니다 — S1: 20봉 최고가 돌파 진입 · 10봉 최저가 이탈 청산, S2: 55봉 · 20봉, S3: 20봉 · 20봉(밴드는 고가 · 저가).
- **봉은 미국 정규장 안에서만 나뉩니다**(TanQuant 백테스트와 같은 봉). 1H = 09:30 … 15:30 시작 1시간봉(마지막은 15:30–16:00), 4H = 그날 1시간봉
  4개씩(09:30–13:30 · 13:30–16:00), 1D = 일봉. 1H · 4H 시세는 야후 파이낸스의 공개 시세를 받습니다(키를 싣지 않습니다).
- **진입.** 완성된 봉의 종가가 진입 밴드를 넘으면(봉마다 한 번 판단) 다음 봉 마감 **10 · 5 · 3분 전**에 목표 수량을 나눠 지정가로 내고, 마감 전에
  못 채운 수량을 현재가보다 1% 높은 지정가로 한 번 메웁니다(한국투자증권 미국주식에는 시장가가 없습니다). 주말 · 휴장일은 건너뛰고, 조기
  폐장일(13:00 ET)에는 그 마감에 맞춥니다.
- **손절.** 진입 신호 가격 − N배수 × ATR(20봉) — 1H 4N · 5N, 4H 3N · 4N, 1D 2N · 3N 가운데 고릅니다. 한국투자증권에는 미리 걸어 두는 손절 주문이
  없어 **봇이 장중 시세로 감시하다가 팝니다.**
- **청산.** 봉 종가가 청산 밴드 아래에서 두 번 이어 닫히면 현재가보다 1% 낮은 지정가로 전량 팝니다 — 장중에 확정되면 바로, 장 마감 뒤에
  확정되면(일봉 · 그날 마지막 시간봉) 다음 정규장이 열린 뒤.
- **장 시간 밖에는 쉽니다.** 미국 정규장(09:30–16:00 ET, 한국 시간 22:30–05:00 · 서머타임이 아니면 23:30–06:00)과 마감 뒤 30분(마지막 봉으로
  진입을 판단하는 시간) 밖에는 증권사를 부르지 않고 쉬다가, 개장하면 자동으로 이어 갑니다. 메인 메뉴에 장 상태와 다음 개장 시각이 보입니다.
- **크기.** 총 시드 × 종목별 배정 %(1~100) ÷ 가격, **1주 단위**(1주 값에 못 미치면 건너뛰고 알립니다). 실현 손익(이익 · 손실)을 다음 진입에
  반영할지(복리) 고릅니다. 주문 가능 현금(금고 제외)이 총 시드보다 10% 적을 때마다 새 진입 크기를 20% 줄이고, 50% 이상 적으면 새로 진입하지
  않습니다(OKX · Gate 봇과 같은 규칙 — 이미 보유 주식에 들어간 돈도 현금에서 빠지므로 보유가 많을수록 새 진입이 작아집니다).
- **보관 규칙(선택).** 이익으로 판 뒤 총자산(현금 + 보유 매입금 — 평가손익 제외)이 기준보다 정한 % 이상 늘었으면 총자산의 정한 % 를 금고에,
  가격이 기준가보다 정한 % 내리면 금고에서 다시 투입합니다.
  증권 계좌에는 따로 옮길 지갑이 없어 금고는 **같은 계좌 안에서 매매에 쓰지 않고 떼어 두는 금액**입니다.
- 매일 09:00(한국 시간) 현황 리포트. 설정은 전부 텔레그램에서 합니다(한국어). TanQuant 백테스트 세팅을 붙여 넣어 한 번에 넣을 수도 있습니다.

## 동작 방식

- **미리 빌드한 이미지.** 워커는 Docker Hub 의 `docker.io/exitant/exitant-turtle-hantoo:latest` 를 받습니다. 이미지에는
  컴파일된 실행 파일만 있고 파이썬 소스는 없습니다.
- **키는 내 것.** 키는 내 Render 환경변수에만 들어가고 한국투자증권 외에는 어디로도 보내지 않습니다.
- **디스크 불필요.** 설정 · 손절가 · 진행 중인 진입은 봇이 텔레그램에 **고정해 두는 백업 메시지**로 재시작 뒤 되살립니다 — 그 고정 메시지를 지우지 마세요.

## 주의

- **손절은 봇이 돌고 장이 열려 있을 때만 걸립니다.** 장이 닫힌 사이의 갭 하락은 막지 못하고, 🛑 완전 중지 · 서버 중지(Suspend) 동안에는
  손절 감시도 멈춥니다(보유 주식은 계좌에 그대로 남습니다).
- **🛑 완전 중지는 서버가 다시 시작되면 풀립니다** — 재시작은 저장된 설정으로 늘 매매를 이어 갑니다. 멈춰 두려면 Render 에서 서비스를 **Suspend** 하세요.
- **인스턴스는 1개로 둡니다.** 2개 이상이면 텔레그램 `getUpdates` 충돌로 봇이 답하지 않습니다(`numInstances: 1`).
- Render **백그라운드 워커에는 무료 요금제가 없습니다** — Starter 이상을 고르세요.
- **「아니오 — 실전 투자」를 고르면 첫 시작부터 실거래입니다.** 처음이면 모의 투자로 한 바퀴 돌려 보거나, 작은 금액으로 시작해 진입 → 청산 한 바퀴를
  계좌에서 확인한 뒤 늘리세요. 투자 판단과 손실의 책임은 이용자에게 있습니다.
